# GAIA Code: Autonomous Coding Agent

GAIA Code is an autonomous coding agent that exceeds Claude Code in capability, autonomy, and reliability through the Recursive Agent Composition (RAC) architecture.

## Key Features

### 🔄 Recursive Decomposition
When tasks are too complex, GAIA Code automatically breaks them down into smaller subtasks and delegates to sub-agents with fresh context windows.

### ✅ Quality Gates
The agent CANNOT declare "done" until all quality gates pass:
- **Syntax Check**: All code parses without errors
- **Import Check**: All imports resolve successfully
- **Test Check**: All tests pass

### 💾 Persistent Memory
Learns across sessions using 7 databases:
- **memory.db**: Session cache
- **knowledge.db**: Cross-session learnings
- **tools.db**: Tool registry (70+ tools)
- **skills.db**: Learned workflows
- **agents.db**: Specialist registry (7+ specialists)
- **plan.db**: Hierarchical task tree
- **manifest**: Live project state

### 🔁 Checkpoint/Resume
Survives crashes and interruptions with zero information loss. State-based resume (not summary-based).

### 🎯 7 Domain Specialists
- **DebuggerAgent**: Error diagnosis and fixing
- **SecurityAgent**: OWASP Top 10 vulnerability detection
- **RefactoringAgent**: Code cleanup and optimization
- **TestingAgent**: Test generation and validation
- **DocumentationAgent**: Docs and docstring generation
- **PerformanceAgent**: Profiling and optimization
- **ArchitectureAgent**: SOLID principles and design patterns

### Python API

```python
from pathlib import Path
from gaia.agents.gaia_code import GaiaCodeAgent

# Create agent
agent = GaiaCodeAgent(
    workspace_dir=Path.home() / ".gaia" / "workspace",
    enable_quality_gates=True,
    enable_continuous_execution=True,
)

# Execute task
result = agent.process_query("Build a REST API with auth")

if result["success"]:
    print("✅ Task completed!")

    # Check quality gates
    for gate in result["quality_gates"]:
        status = "✅" if gate.passed else "❌"
        print(f"{status} {gate.gate_name}: {gate.message}")

# Get progress
progress = agent.get_progress()
print(f"Progress: {progress['progress_percent']}%")
print(f"Tasks: {progress['completed']}/{progress['total_tasks']}")
```

## How It Works

### Recursive Agent Composition (RAC)

Instead of a single monolithic agent, GAIA Code is a system of agents that recursively spawn sub-agents:

```
Main Agent receives: "Build a full-stack app"
   │
   ├─> agent_query("Build FastAPI backend with auth")
   │      ├─> agent_query("Create data models")
   │      ├─> agent_query("Implement auth endpoints")
   │      └─> agent_query("Write tests")
   │
   └─> agent_query("Build React frontend")
          ├─> agent_query("Set up React app")
          ├─> agent_query("Create components")
          └─> agent_query("Write tests")
```

**Key Benefits**:
- Each sub-agent gets fresh context window
- Context never fills up
- Perfect coordination via shared state
- Specialists handle domain-specific tasks

### Context-Lean Architecture

Traditional agents fill the context window:
```
Claude Code: Context Window (200K tokens)
├── System prompt
├── File contents (all)
├── Tool results (all)
├── Conversation history (all)
└── ... fills up, needs compaction ⏳
```

GAIA Code keeps context lean:
```
GAIA Code: Context Window (<50% usage)
├── System prompt
├── Current task
├── Active file snippet
└── Last few tool results

Knowledge DBs (external storage):
├── memory.db (session cache)
├── knowledge.db (learnings)
├── tools.db (tool registry)
├── skills.db (workflows)
└── agents.db (specialists)
```

**Result**: Context never fills up. No compaction. No slowdowns.

### Quality-Driven Completion

The agent runs until output is verified correct:

```python
while not all_quality_gates_pass():
    execute_task()
    run_quality_gates()

    if gates_fail:
        if should_retry:
            retry()
        elif should_decompose:
            agent_query(subtask)  # Break into smaller pieces
        elif should_escalate:
            escalate_to_cloud()
        else:
            ask_user()
```

**Escalation Ladder**:
1. Retry (2 attempts)
2. Decompose into smaller subtasks
3. Escalate to cloud LLM (if available)
4. Ask user for help

## FAQ

### How is GAIA Code different from Claude Code?

1. **Context-Lean**: Never fills context window (Claude Code requires compaction)
2. **Quality Gates**: Verifies output works (Claude Code doesn't automatically test)
3. **Persistent Memory**: Learns across sessions (Claude Code forgets)
4. **Specialists**: 7 domain experts (Claude Code is generalist)
5. **Recursive Decomposition**: Automatic task decomposition (Claude Code requires manual prompting)

### Can GAIA Code work with large codebases?

Yes! GAIA Code uses recursive decomposition. It never tries to fit a large codebase into context. Instead, it:
- Indexes the codebase
- Queries the index semantically
- Reads only relevant files
- Uses agent_query() to analyze different parts recursively

### Does it require cloud LLM?

No! GAIA Code works with local LLMs (Qwen3-Coder-30B) via Lemonade Server. It can optionally escalate to cloud (Claude/GPT-4) for difficult subtasks.

### How does checkpoint/resume work?

GAIA Code saves complete state (not just summaries):
- Master plan with all tasks
- Audit log with all actions
- Escalation ladder state
- Session metadata

Resume picks up EXACTLY where it left off. Zero information loss.
