## 1. Executive summary

GAIA's security primitives are individually good and collectively unenforced. Constant-time compares, atomic 0600 secret files, an SQLite authorizer allow-list for LLM SQL, a real SSRF validator with DNS-rebind protection, HMAC-signed RAG caches, Ed25519 skill signing, a confirmation gate that MCP and REST paths cannot bypass, OIDC publishing behind a single approval — each exists, and each is skipped at some call site that forgot to invoke it. That is the shape of almost every finding here: primitives that exist but are not wired everywhere, boundaries enforced by convention rather than by construction, tests that prove a call happened rather than that it was valid, and a Windows platform no automated unit lane exercises. (Appendix C lists ~150 things that were checked and found sound.)

This review confirmed **{{NC}} critical and {{NI}} important findings (consolidated IDs; the raw reports hold 34 🔴 / 153 🟡 / 82 🟢 entries before merging) plus ≈120 distinct minor items**. {{PROBES}} of the critical/important findings were reproduced by executing a probe, four more against live systems or the installed binary. Every one was then independently re-verified by a second pass: two sub-claims were refuted (a CORS wildcard that does not exist; a shell operator that is in fact blocked), three findings were overstated and re-ranked, ~40 citation, count and wording corrections were applied, and six new criticals were found in files the first pass had listed as unread. Ten criticals carry or name an open issue (#124, #630, #1128, #1344, #1460, #2474, #2768, #2803, #2951, #3316); none is fully tracked.

### Ten themes to fix first (≈25 changes)

1. **The release is blocked three ways** (C39): tagging `v0.23.1` fails two of `publish.yml`'s own validators, the release gate (`email-eval`) is red on Anthropic billing, and two other workflows race the tag before any approval. The notes also tell users to run a command that does not exist. Fix all three, then tag — and add the validators at PR time so it cannot recur.
2. **The per-agent connector grant model is dead** (C1, C17, I14): tool bodies run on a thread that drops the agent identity and the connectors layer treats "no identity" as "skip the check"; the ledger it would check can be set to any scope by any local caller; the Tavily key is handed out ungated regardless. One `copy_context().run`, a fail-closed default, and a scope ceiling — landed together.
3. **Three PowerShell injection sinks and a shell allowlist that is not a boundary** (C2, C3, C4, C5): `notify_desktop` interpolates model text; indexing a PPTX interpolates its *filename* (no model involved); unspaced `&`, `-e`, aliases and `.NET`/WMI calls run through `cmd.exe` as "read-only" — behind one confirmation click, or none under auto-approve or an "always" grant; a granted `gh` skill can print the user's PAT.
4. **`allowed_paths` is bypassed by fifteen tools across six families, is silently widened to `$HOME` by attaching a document, and has no sensitive-file denylist on reads** (C7, C8, I13) — while three docs call it the production security boundary and one unit test pins the bypass as intended. Reads of `~/.ssh/id_rsa` and writes to `~/.bashrc` both pass today.
5. **Local HTTP surfaces are drive-by exploitable from any web page**: 41 CSRF-able Agent UI routes — one body-less POST opened a real public tunnel during verification (C11); a wildcard trust of every `*.ngrok-free.app` origin that defeats the CSRF guard entirely (C12); the MCP bridge's `ACAO: *` (C13); the base `AgentServer` and OpenAI API with no auth (C10). The tunnel token, when it applies, is a read token for the entire home directory (I34).
6. **Esc does not stop the shipped agent** (C30): the TUI kills only the PyInstaller bootloader; the real process finishes the cancelled tool call, eats the next message, and a respawn silently reverts `/bypass off` (C31). Verified against the installed binary.
7. **`gaia uninstall --purge` can delete `~/Documents`** when `GAIA_HOME` points at home (C23); `gaia kill --port` / `gaia api stop` kill unrelated processes (C24); `replace_function` deletes neighbouring code and the target's decorators (C25); `download_file` overwrites user files with attacker-named content (C26); `gaia skill remove .` wipes `~/.gaia/skills` incl. the signing keys (C22); a chat turn can mint `system`/`profile`/`permission` memory rows that lead every future system prompt (C16).
8. **Shipped features that are broken outright**: every `/v1/chat/completions` request to `gaia api` raises `TypeError` (C27 — the test uses a `MagicMock` agent); web fetch fails on 9 of 11 tested sites incl. `example.com`, `github.com` and `amd-gaia.ai` because the IP-pinning adapter sends no SNI (C32 — a documented "residual limitation", now measured); memory consolidation never completes for sessions over 20 turns, re-stores duplicates every boot, and the raw turns are then pruned (C28); the renderer deletes ```` ```shell ```` blocks and JSON examples from answers (C29); `gaia talk` never pauses the mic while it speaks and ignores `--model` (C33, C34 — #124 open since v0.13); a chat turn can hang forever on a prompt printed to the server's terminal (C37); `import gaia` dies in any process without a resolvable home dir (C38).
9. **Electron and the C++ framework**: one click on an LLM-rendered link can launch a local binary (C14, verified resolution); "Always allow" is a permanent hidden client-side bypass (C15); a missing method crash-exits the app during agent crash loops (C35); "Open in GAIA" fails on cold start (C36); the C++ MCP client hands server arguments to `/bin/sh -c` unescaped (C19).
10. **The quality gates are aspirational**: no CI lane runs `tests/unit` on Windows and ≈640 tests (overlapping tallies across the sampled trees) are red there (C41); the release build's own test step ends in `|| echo skipped` (C40); fork PRs run unapproved on persistent lab runners (C20) and the publish path uses mutable action tags (C21); the eval gate has never produced a scorecard and 9 of 12 categories have no baseline (I78); ≈43 test files run in no workflow (I75).

### Structural themes (what the findings have in common)

- **Enforcement by convention, not construction.** Sandbox, SSRF guard, CSRF header (defined four times), caller auth, keyring refusal, grant check, category validation — each exists and each is skipped somewhere because a call site forgot it. The fix pattern is the same every time: enforce at registration/middleware/store level, not per call site (§8 items 1–4).
- **Windows is untested.** ≈640 unit tests (overlapping tallies) are red on a clean Windows checkout for five environmental reasons (C41, I74); the eval serial guard is a no-op there (I76). Several Windows-specific bugs in this report (C4, C24, C38, NTFS ACL gaps, cp1252/CRLF breakage) would have been caught by one `windows-latest` job.
- **Tests that pin bugs as contracts.** At least eleven tests assert the buggy behaviour (§5), and ≈43 test files run in no workflow at all.
- **Duplicate implementations drift.** Four copies of the CSRF guard; three `read_file`s; two web fetchers (one without the SSRF guard); two voice pipelines (the correct one unused); three schedulers; two uninstallers with different `~/.gaia` contracts; three renderer JSON cleaners; five TUI scrubbers; two C++ error decoders; three near-identical release workflows.
- **Silent fallbacks persist** despite the CLAUDE.md rule: ≈95 bare `pass/return/continue` handlers in `src+hub` (densest in `ui/routers/memory.py` and `agents/base/system_context.py`), plus the release build's `pytest … || echo "skipped"` (C40), `gaia init` failures reported as success in the Electron installer (I68), VLM errors returned as document text (I20), integrity failures reported as ordinary staleness (I53), an index-query failure that silently falls back to a filesystem walk (I36).
- **Docs and process drift faster than code.** The roadmap is five months stale; six plans say "0%" for shipped features; CLAUDE.md advertises a cancelled rename and omits five packages; the CLI reference documents 21 `gaia tui` invocations that do not exist; the npm email package links to a tag that was never created; the security-model page has superseded itself (§7).

### What is in good shape

The daemon/custody/relay layer, the connectors OAuth/PKCE/keyring path, the SQL authorizer, the hub installer's archive handling, the embedded Lemonade runtime, the RAG thread-safety and PDF-state work (#746/#784), the email agent's autonomy safety envelope, the TUI control API, `openai_server`'s CORS configuration, and the Electron process-isolation settings are all careful, well-tested, and matched their documentation — see Appendix C before spending review time there again.
